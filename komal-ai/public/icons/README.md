# Komal.ai Custom Icons

You can download and drop any custom `.svg` or `.png` icon files directly into this folder:
`/home/mrblair/Documents/komal ai/komal-ai/public/icons/`

Available default icons:
- `arrow-left.svg` — Sleek back arrow for navigation buttons
- `arrow-up-right.svg` — Diagonal external/link arrow
- `more-horizontal.svg` — Three dots menu icon
- `play.svg` — Audio/session play icon
- `pause.svg` — Audio/session pause icon

To use any icon in the frontend, you can reference it as `/icons/filename.svg`.
When you download new icons, simply overwrite these files or add new ones here!
